# Handmade Bathtub Automation Venture Proposal

## The Problem & Choices
The core challenge is enabling boutique brands like "Handmade Bathtub" to systematically identify high-value B2B and B2C clients, answer custom specifications seamlessly, and scale quote handling without introducing operational friction or full-scale database overhead. 

To respect the strict 6-hour time limit, I chose a low-code architecture using collaborative cloud tracking sheets integrated with a visual front-end interactive mockup framework. This checks and routes multi-channel lead logic cleanly without building heavy backend software dependencies from scratch.

## Technical Strategy & Tradeoffs
An alternative platform architecture evaluated was an automated custom Python app deployed via Docker containers. While highly powerful for direct script modifications, it was dropped because low-code automation blocks allow non-technical business partners to inspect sales leads and modify validation conditions instantly on their phones without code changes.

To protect production realities, the architecture utilizes front-end friction logic. Before routing any lead to a manual quote desk, drop-down constraints force prospects to validate their lead time against the minimum 21-day stone curing timeline.

## Left Out & Next Steps
- Left Out: Live webhook integrations for real-world automated triggers and automated CRM matching logs (omitted due to the strict testing sandbox limitations).
- Future Improvements: Creating standard conditional workflows for high-volume custom sizing validation protocols and implementing direct API-based pricing rules.
